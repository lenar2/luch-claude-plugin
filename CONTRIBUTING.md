# Contributing to LUCH Claude / ChatGPT clients

Keep changes small, verifiable and restricted to the current client and authorized account. Do not publish credentials, private owner endpoints, device IDs or user data.

For any public-facing content (README, onboarding, demo, listing, visuals), I require [the independent HEA Creative Release Gate](https://github.com/lenar2/luch/blob/main/docs/HEA_CREATIVE_GATE.ru.md) and its [review form](https://github.com/lenar2/luch/blob/main/docs/HEA_REVIEW_PACKET.ru.md). The author cannot award an independent PASS. The exact candidate needs signed review, five genuine first-impression tests, visual QA and founder authorization.

Until repository protection rules are configured and tested, **HOLD is a process instruction and not a technical branch lock**. Do not configure GitHub Actions as a workaround.
